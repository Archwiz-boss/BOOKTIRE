# 建照書表資料編輯器

**用瀏覽器把建照無紙化系統的案件資料改得又快又準，改完直接匯回去。**

建照無紙化（二維條碼）系統的案件資料，是一個叫 `data.txt` 的檔案。
它有 13 張表、596 個欄位，格式極度嚴格——順序錯一個、多一個空格、
用了它不認得的字，整份就匯不進去。

在原系統裡改這些資料，往往要一頁一頁點、一格一格填。
這個工具把同一份資料攤開成好操作的畫面：

- 左邊直接切換「建照申請 / 施工管理 / 使用管理 / 拆除」四大類書表
- 地號、樓層、所有權人這種一長串的資料，**可以直接從 Excel 複製貼上一整塊**
- 縣市 → 行政區 → 地段會連動，打幾個字就搜尋得到，不必背代碼
- 存檔前自動檢查，格式有問題會先告訴你，而不是到系統才被退件

<br>

## 🔒 先講最重要的：你的資料不會傳給任何人

**這個工具沒有雲端，也沒有會員。沒有任何一份案件資料會傳到我這裡或其他伺服器。**

| 你用的方式 | 資料在哪裡處理 | 誰看得到 |
|---|---|---|
| 下載桌面版程式 | 你自己的電腦 | 只有你 |
| 線上試用版網頁 | 你自己的瀏覽器 | 只有你 |

線上試用版雖然是網頁，但它是「**你打開網頁後，程式跑在你的電腦上**」——
就像下載了一個小程式在瀏覽器裡跑一樣。你選的檔案從頭到尾沒有被上傳過。
你可以開啟後直接把網路拔掉，一樣能繼續改、繼續存檔。

存檔也是直接存回你自己的電腦，跟平常下載檔案一樣。

## 怎麼用？三步驟

### 步驟 1️⃣ 從無紙化系統匯出你的案件

在**建照無紙化系統**裡，把要修改的案件用「**匯出專案**」功能存成一個 ZIP 檔。

### 步驟 2️⃣ 丟進這個工具改

把那個 ZIP 檔**直接拖進**編輯器畫面（或按左上角「載入 data.txt／ZIP」）。
案件資料就會攤開在畫面上，開始改。

改完後按右上角「**匯出**」→「**匯出原 ZIP（替換 data.txt）**」，
會得到一個檔名結尾是 `_updated.zip` 的新檔案。

### 步驟 3️⃣ 匯回無紙化系統

把那個 `_updated.zip` 拿回**建照無紙化系統**用「匯入」功能匯進去，完成。

> **為什麼要用 ZIP 進、ZIP 出？**
> 因為無紙化系統的 ZIP 裡除了 `data.txt` 還有別的檔案。
> 這個工具**只換掉 `data.txt`，其他檔案原封不動**，
> 所以匯回去不會有問題。如果你只單獨匯出 `data.txt`，
> 就得自己想辦法塞回原本的 ZIP 裡，比較麻煩。

📖 每個畫面、每個按鈕的詳細說明，請看 👉 **[使用手冊](docs/使用手冊.md)**

## 它能做什麼

- **四大類書表都能編**：建照申請（A）、施工管理（B）、使用管理（C）、拆除（D），
  共 19 個資料群組。同一份案件資料在不同書表之間共用，不用重複填。
- **Excel 整塊貼上**：地號、樓層面積、所有權人這類會有幾十列的資料，
  在 Excel 排好後整塊複製，貼進「批次輸入」表格就好。
- **不用背代碼**：縣市選好會自動篩出行政區，行政區選好會篩出地段。
  搜尋框可以打中文名稱或代碼，例如打「福安 4662」就找得到。
- **一鍵帶入原核准資料**：變更設計時，把本次資料整批複製到「變更前」欄位，
  兩邊不一樣的地方會標紅點，一眼看得出改了哪裡。
- **存檔前先檢查**：主鍵、序號、數字格式、系統不認得的字，會在匯出前一次列出來。
- **不會弄壞你的檔案**：如果你載入後什麼都沒改就匯出，
  出來的檔案跟原檔**一模一樣，連一個位元組都不差**（這是本專案的最高驗收標準，有自動測試把關）。
- **中文為主**：畫面顯示中文欄位名稱，需要對接系統時才切換顯示原始英文欄名。

## 常見問題

**Q：我需要會寫程式嗎？**
不用。下載桌面版雙擊就能用，或直接開線上試用版。

**Q：需要付錢嗎？**
不用。MIT 授權，免費使用，也可以自由修改和散布。

**Q：會不會把我的案件資料傳出去？**
不會。詳見上面「[你的資料不會傳給任何人](#-先講最重要的你的資料不會傳給任何人)」。

**Q：桌面版打開是一個黑色視窗，正常嗎？**
正常。那是服務的執行視窗，**使用期間請不要關掉它**。
真正的操作畫面會自動用瀏覽器開啟。用完先在瀏覽器存好檔，再關掉黑色視窗即可。

**Q：下載 exe 時 Windows 跳出藍色警告？**
正常，因為這個程式沒有買微軟的數位簽章（要年費）。
處理方式請看 [使用手冊的說明](docs/使用手冊.md#windows-跳出藍色警告怎麼辦)。

**Q：這是政府official的工具嗎？**
**不是。** 這是非官方的第三方輔助工具，跟內政部營建署沒有關係。
工具只負責把資料整理成系統看得懂的格式；**內容正不正確、合不合法規，
仍然要由設計人自己負責**。

**Q：資料改壞了怎麼辦？**
建議每次改之前先留一份原始 ZIP 的備份。
工具本身不會動到你原本的檔案，匯出時都是產生新檔案。
