## 第一次使用：安裝與啟動

### 選項 A：線上試用版（不用安裝）

打開瀏覽器，前往 **<https://archwiz-boss.github.io/BOOKTIRE/>**

第一次開啟會看到「正在準備線上試用版」的畫面，等 10～30 秒即可。
（它在下載執行環境，約 10 MB。之後再開啟就快很多，因為瀏覽器記住了。）

看到編輯器畫面就可以開始用了。

### 選項 B：桌面版（推薦長期使用）

#### 1. 下載

前往 **<https://github.com/Archwiz-boss/BOOKTIRE/releases/latest>**

在頁面往下捲，找到 **Assets** 區塊，點 **`CPAMI-Editor.exe`** 下載。
檔案約 10 MB。

#### 2. 放到你想放的地方

這個檔案**不需要安裝**。放桌面、放 D 槽、放隨身碟都可以，
複製給同事也可以直接用。

#### 3. 雙擊執行

##### Windows 跳出藍色警告怎麼辦？

第一次執行時，Windows 很可能會跳出一個藍色視窗：

> **Windows 已保護您的電腦**
> Microsoft Defender SmartScreen 已防止某個無法辨識的應用程式啟動…

這**不是病毒警告**。它的意思是「這個程式沒有買微軟的數位簽章，我不認識它」。
數位簽章要付年費，免費開源專案通常不會買。

處理方式：

1. 點視窗裡的「**其他資訊**」
2. 下方會出現「**仍要執行**」按鈕，點它

之後再執行就不會再問了。

> 如果你不放心，可以把 exe 丟到 [VirusTotal](https://www.virustotal.com/) 掃一下，
> 或者乾脆用[方式三：自己從原始碼跑](開發指南.md)——原始碼全部公開，可以自己檢查。

#### 4. 啟動後會看到什麼

會出現**兩個東西**：

**（一）一個黑色的文字視窗**，內容類似：

```
==============================================================
  CPAMI 建照書表資料編輯器
==============================================================

  服務已啟動，瀏覽器會自動開啟下面這個網址：

      http://127.0.0.1:8765/

  目前只有這台電腦可以連線（其他電腦連不進來，最安全）。

  ── 請注意 ──────────────────────────────────────────
  1. 使用期間請「不要關掉這個黑色視窗」，關掉服務就停了。
  2. 案件資料只存在瀏覽器分頁裡，改完一定要按「匯出」存檔。
  3. 要結束時，先在瀏覽器存好檔，再關掉這個視窗即可。
  ────────────────────────────────────────────────────
```

**這個黑色視窗就是程式本體，使用期間請不要關掉它。**

**（二）瀏覽器會自動打開編輯器畫面**，這才是你要操作的地方。

#### 5. 結束使用

1. 先在瀏覽器裡按「匯出」把檔案存好
2. 關掉瀏覽器分頁
3. 關掉黑色視窗（或在裡面按 `Ctrl + C`）

## 完整工作流程

以下是最常見的完整流程：**把無紙化系統的案件拿出來改，再放回去。**

### 步驟 1：在無紙化系統匯出專案

打開**建照無紙化系統**，找到你要修改的案件，
使用「**匯出專案**」功能，把案件存成一個 ZIP 檔到你的電腦。

> 這個 ZIP 裡面除了案件資料 `data.txt`，通常還有圖說、附件等其他檔案。

### 步驟 2：把 ZIP 載入編輯器

有兩種方式，效果一樣：

- **拖進去**：直接把 ZIP 檔案拖曳到編輯器畫面上，放開
- **用按鈕**：點左上角「**載入 data.txt／ZIP**」，選擇該 ZIP 檔

載入成功後，畫面上方的狀態列會顯示來源檔名，左側的資料群組就有內容了。

### 步驟 3：修改資料

在左側選要編輯的資料群組（例如「案件主檔」「基地地號」「樓層用途面積」），
在右邊填寫或修改。

每改一個地方，狀態列會提醒你「尚未匯出」。詳細技巧見
[常用操作技巧](#常用操作技巧)。

### 步驟 4：檢查

改完後，點右上角「**更多**」→「**檢查資料**」。

系統會列出所有問題，分成兩種：

- 🔴 **錯誤（errors）**：一定要改掉，否則匯不出去
- 🟡 **警告（warnings）**：建議看一下，但不影響匯出

### 步驟 5：匯出成 ZIP

點右上角「**匯出**」→「**匯出原 ZIP（替換 data.txt）**」。

你會下載到一個檔名結尾是 `_updated.zip` 的檔案。

> **這個選項只有「從 ZIP 載入」時才能點。**
> 如果你是載入單獨的 `data.txt`，就只能匯出單獨的 `data.txt`。

**這個做法的好處**：工具只換掉 ZIP 裡的 `data.txt`，
其他所有檔案（圖說、附件）的內容和路徑**原封不動**，
所以匯回無紙化系統不會出問題。

### 步驟 6：匯回無紙化系統

回到**建照無紙化系統**，用「匯入」功能，選擇剛剛下載的 `_updated.zip`。

完成。

```
┌──────────────────────────────────────────────────────────┐
│ [二維] 建照書表資料編輯器    [載入] [匯入CSV] [更多] [匯出] │ ← 頂部工具列
├────────────┬─────────────────────────────────────────────┤
│ 書表組     │                                             │
│ ○ 建照申請 │   目前記錄  [＋新增] [複製] [刪除]           │
│ ○ 施工管理 │   [共用範本] [批次輸入] [清空本頁]           │
│ ○ 使用管理 │                                             │
│ ○ 拆除     │   ▼ 基本資料                                │
│            │      縣市      [臺中市        ▾]            │
│ 資料群組   │      行政區    [清水區        ▾]            │
│ • 案件主檔 │      地段      [福安段        ▾]            │
│ • 基地地號 │                                             │
│ • 起造人   │   ▼ 面積資料                                │
│ • 樓層用途 │      總面積    [        ] ㎡                │
│ • ...      │                                             │
├────────────┴─────────────────────────────────────────────┤
│ ✓ 已載入 案件.zip                              尚未匯出  │ ← 狀態列
└──────────────────────────────────────────────────────────┘
```

### 頂部工具列

| 按鈕 | 做什麼 |
|---|---|
| **載入 data.txt／ZIP** | 開啟既有案件。也可以直接把檔案拖進畫面 |
| **匯入 CSV／XML** | 從 Excel 或其他系統把資料對接進某個資料群組 |
| **更多** | 全案清空、載入／匯出完整案件 JSON、下載範例檔、檢查資料 |
| **匯出** | 匯出 data.txt，或匯出替換過的原 ZIP |

### 左側欄

- **書表組**：切換「建照申請 / 施工管理 / 使用管理 / 拆除」四大類。
  **切換只是換個角度看同一份案件，不會複製或清掉資料。**
- **資料群組**：目前書表組底下可以編輯的各張表。
  名稱前面有 `*` 表示「依你填的申請類型，建議優先填這個」——
  這只是提示，不會擋你填別的。
- **書表目錄**：這個書表組包含哪些書表，供對照用。

### 記錄操作區（右上）

有些資料群組會有很多筆（例如地號有 20 筆、所有權人有 5 個），
這時用這排按鈕管理：

| 按鈕 | 做什麼 |
|---|---|
| **＋** | 新增一筆空白記錄 |
| **複製** | 複製目前這筆（識別碼、建立日期會自動清空） |
| **刪除** | 刪掉目前這筆 |
| **批次輸入** | 打開表格模式，可以整塊貼上 Excel 資料（很好用，見下） |
| **清空本頁** | 只清掉目前這個群組，其他不動 |

### 狀態列（最下方）

- 🟢 綠色：正常，已完成
- 🟡 黃色：有東西還沒存，或正在處理
- 🔴 紅色：有錯誤

**只要你改了任何東西，狀態列就會顯示「尚未匯出」提醒你存檔。**

## 常用操作技巧

### 從 Excel 整塊貼上（最省時間的功能）

適用於地號、樓層面積、所有權人這類會有很多列的資料。

1. 在左側選好資料群組（例如「基地地號」）
2. 點右上角「**批次輸入**」
3. 在 Excel 裡選取你要的那一塊資料，`Ctrl + C` 複製
4. 回到批次表格，點你要開始貼的那一格，`Ctrl + V`

**貼上的資料如果第一列是欄位名稱（中文或英文都可以），
系統會自動認出來當標題，不會誤存成資料。**

其他好用的：

- 「**新增 10 列**」：先開好空列再慢慢填
- 「**全選**」：全部選起來後，同一顆按鈕會變成「取消全選」
- 關掉批次表格時，**修改會自動保留**，序號也會自動重排

### 不用背代碼

代碼欄位會依照你已經選的內容自動縮小範圍：

**縣市 → 行政區 → 地段**

選項不多（5 個以內）時直接是下拉選單；選項多的時候會開一個搜尋視窗：

- 可以打**中文名稱**或**代碼**
- 空格可以組合多個關鍵字，例如 `福安 4662`
- 用 `↑` `↓` 移動，`Enter` 選取
- 最近選過的會出現在最上面

選好之後，配對的說明文字會自動幫你帶進去（**只填空的，不會蓋掉你已經打的字**）。

### 變更設計：一鍵帶入原核准資料

做變更設計時，需要同時有「本次」和「變更前（原核准）」兩份資料。

在「基地地號」「樓層用途面積」「雜項工作物」這幾個群組，
右側有「**一鍵帶入本次地號 / 樓層概要**」按鈕，
會把本次的資料整批複製到「變更前」欄位。

在批次表格裡，可以用上方按鈕切換看「本次 / 變更前」：

- 🔴 **列旁邊有紅點**：這一列兩邊不一樣
- 🔴 **格子右下角有紅點**：這一格兩邊不一樣

> 注意：帶入是「逐欄覆蓋」。本次欄位如果是空的，
> 對應的原核准欄位也會被清成空的，避免留下舊資料。

### 案件備註：不用自己打

進入「案件備註」頁面，上方有引導區：

**選分類 → 選程序 → 選內容範本 → 確認全文 → 新增**

裡面收錄了舊系統的 6 大分類、52 個程序、89 則制式備註全文。
加進去之後還是可以自己改字。

不在清單裡的內容，按「**新增自由備註**」自己打。

### 顯示原始欄名

畫面預設顯示中文欄位名稱。如果你需要對接系統、寫 CSV，
可以打開「**顯示原始欄名**」看到英文欄名（例如 `BMPAS`、`SECTION`）。
這個設定會被記住。

## 存檔的三種格式，該用哪一種

| 格式 | 什麼時候用 | 怎麼做 |
|---|---|---|
| **原 ZIP（替換 data.txt）** | ⭐ **要匯回無紙化系統，用這個** | 匯出 → 匯出原 ZIP |
| **data.txt** | 只需要單獨的資料檔 | 匯出 → 匯出 data.txt |
| **完整案件 JSON** | 工作做到一半要存草稿 | 更多 → 匯出完整案件 JSON |

### 為什麼會有「完整案件 JSON」？

因為施工管理（B）和使用管理（C）有些資料——例如使用道路、施工勘驗、
逐月材料人力、施工照片附件——**舊系統的 `data.txt` 格式裡根本沒有位置放**。

- 匯出 `data.txt` 時，這些資料**不會**被寫進去（也不能寫，會破壞格式）
- 匯出「完整案件 JSON」時，這些資料**會**完整保存，包含附件內容

所以：

> **做到一半要收工 → 存「完整案件 JSON」，下次用「載入完整案件 JSON」接著做。
> 要送件 → 匯出 ZIP 或 data.txt。**

## 疑難排解

### 雙擊 exe 後黑色視窗一閃就不見了

通常是連接埠被其他程式占用。程式會自動往後找可用的埠，
如果連續 20 個都被占用才會失敗。

試著：重開機再試，或在命令提示字元裡執行
`CPAMI-Editor.exe --port 9000` 換一個埠。

### 瀏覽器沒有自動打開

黑色視窗裡有寫網址（通常是 `http://127.0.0.1:8765/`），
自己複製貼到瀏覽器網址列即可。

### 匯出時說「CP950 無法表示的字元」

`data.txt` 用的是舊的 Big5／CP950 編碼，有些字它表示不出來，
最常見的是：

- 罕見字、異體字（例如某些姓名用字）
- 從網頁複製過來的**全形符號**或特殊符號
- 表情符號

**工具會明確告訴你是哪一欄、哪個字**。把那個字換成 Big5 有的字即可。

> 這個檢查不能拿掉。如果硬要匯出，那個字會變成 `?`，
> 送件後可能造成資料錯誤。

### 匯出時說欄位有錯

點「檢查資料」看完整清單。常見的：

| 訊息 | 意思 |
|---|---|
| `INDEX_KEY 不一致` | 13 張表的案件識別碼要相同，通常是手動改壞了 |
| `person_seq 重複` | 同一張表裡的序號不能重複，用批次表格關閉時會自動重排 |
| `數字欄含非數字` | 數字欄位不能有單位、逗號，例如要填 `1000` 不是 `1,000 ㎡` |

### 載入 ZIP 說「找不到 data.txt」或「有多個 data.txt」

- ZIP 裡**必須有且只有一個** `data.txt`（放在哪個子目錄都可以）
- ZIP 不能加密
- 確認是從無紙化系統「匯出專案」出來的檔案，不是自己壓的

### 改到一半瀏覽器關掉了，資料還在嗎？

**不在。** 案件資料只存在瀏覽器分頁的記憶體裡，關掉就沒了。

這是刻意的設計——資料不落地，就不會有個資殘留在電腦上的問題。
但代價是**你必須自己按匯出存檔**。

建議工作到一段落就存一次「完整案件 JSON」當草稿。

### 線上試用版一直卡在「正在準備」

可能是公司網路擋掉了 CDN。改用桌面版（exe），完全不需要網路。

## 安全與隱私

### 資料流向

**你的案件資料從頭到尾都在你自己的電腦上。**

- 桌面版：程式跑在你的電腦，資料在你的電腦，存檔存到你的電腦
- 線上試用版：網頁下載到你的瀏覽器後，**程式在你的瀏覽器裡跑**，
  檔案是你在本機選的、存回本機的，沒有上傳

作者（以及任何其他人）**看不到、也拿不到**你的任何案件資料。

### 桌面版的連線範圍

雙擊啟動的桌面版**預設只有這台電腦連得進來**（`127.0.0.1`），
其他電腦連不到，這是最安全的設定。

如果你需要讓辦公室裡其他電腦或手機也能連進來用，
可以用參數啟動：

```
CPAMI-Editor.exe --lan
```

這時黑色視窗會列出內網網址（例如 `http://192.168.1.100:8765/`），
同一個區域網路的裝置就能連。

> ⚠️ **注意事項**
> - 本服務**沒有 HTTPS 加密**，只適合在可信任的內部網路使用
> - 案件含身分證字號、地址等個資，**不要把它暴露到網際網路上**
> - 需要遠端使用請走 VPN

### 共用範本模式會存東西到硬碟

如果你用 `--sqlite` 參數啟動，起造人、建築師事務所這類重複資料
可以存成範本重複使用。這些範本會存在 exe 旁邊的 `runtime\sqlite\` 資料夾。

> 那個資料庫檔可能包含姓名、身分證字號、地址、電話。
> **請納入你單位的備份與存取控管，不要外傳。**

完整案件**不會**存進去，仍然只在瀏覽器記憶體裡。
